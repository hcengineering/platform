# @hcengineering/server-praut-workflow

PRAUT server-side workflow package.

This is the green-area home for backend rules tied to the PRAUT lead-to-project workflow. The scaffold intentionally has no runtime behavior yet.

Allowed future responsibilities:

- opportunity approval audit helpers
- idempotent project handoff preparation
- low-risk notifications for responsible users
- validation of missing required workflow fields

Do not put pricing, legal, or customer-facing auto-send behavior here without explicit human approval and audit design.
